DOCUMENTATION & ARCHITECTURE

Framework Guide

Technical guide to automated fuzz testing, classification heuristics, and quality metrics.

1. OpenAPI / Swagger Parsing & Reference Resolution

SentinelAPI ingests OpenAPI 3.x and Swagger 2.0 specifications. It traverses JSON/YAML schemas, recursively resolves all internal $ref dependencies, and maps each operation's path, query, header, and body constraints.

2. Fuzz-Risk Scoring Heuristic

Endpoints are prioritized based on structural risk factors: mutating HTTP methods (POST, PUT, DELETE), dynamic request bodies, complex path/query parameters, and lack of authentication barriers.

3. Hostile Payload Generation

The input synthesizer generates boundary values (integer overflow, negative bounds, max lengths), type confusion (arrays/objects in primitive slots), SQL Injection indicators, XSS script injection strings, and path traversal strings.

4. Independent Anonymous Probes

Secured endpoints automatically receive an independent unauthenticated probe without credentials. A 2xx response triggers an immediate AUTH_NOT_ENFORCED finding.
